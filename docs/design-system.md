# レシわけのデザイン

白・墨色・朱赤を基本に、余白、文字の強弱、線の太さで情報の順序を作る。LPの下線や金額欄の上辺などに特徴を持たせる。操作部品は画面をまたいで形・色・大きさを統一する。レシートの見本はLPの一箇所に置き、紙の切り口を各画面へ繰り返さない。入力内容はラベル・数値・単位の組み合わせで示し、説明段落を読まなくても操作できる形にする。装飾用の英語ラベルや、見出し・数値と同じ情報を繰り返す注記は置かない。

## 視覚的な工夫

- ロゴとfaviconは、1枚のレシートを2片に分けた共通マークを使う。
- LPの見出しは朱赤の下線、冒頭のレシート見本は傾きと紙の切り口で特徴をつける。
- 見本の金額と手順番号には等幅フォントを使う。手順番号は小さな番号札として示す。
- 作成画面は外枠を置かず、セクション間の余白と品目間の薄い横線で区切る。入力欄には共通の境界線と角丸を使う。飲み会の名前にはラベルを上に置く。立替者と人数は「[名前] が立て替え」「自分も含めて [人数] 人で割り勘」と文の中に入力欄を置き、品目の数量・合計はラベルと入力欄を横に並べる。
- 選択画面は行全体を着色せず、本人の金額を朱赤、品全体の金額を控えめな文字で示す。数量と金額は同じ行にまとめ、その下に1杯・1品ずつのタイルを並べる。タイルは52px角で、狭い画面では折り返す。

## 情報と数値の見せ方

- 金額は `1,200 / 1,800 円`、数量は `2 / 3` と表示する。左は本人の負担額・食べた飲んだ数、右はその品全体の金額・総数に統一する。右側を残り数や人数に置き換えない。
- 金額の比率表示は `AmountRatio` を共用する。品全体の金額には税・値引きの配分を含め、読み上げでは本人の負担額と全体額を区別する。数量にも読み上げ用の意味を付ける。
- `負担 / 全体` は一覧の見出しに一度だけ置く。各行に「あなたの分」「全体」「自分の数」といったラベルを重ねない。
- 食べた・飲んだ分だけ、1杯・1品を表すタイルを押す。選択済みは朱赤とチェック、ほかの人の分はグレーと人物マークで区別する。品名は行の見出しに一度だけ置き、タイルに番号やラベルを繰り返さない。数量は `2 / 3` を残す。
- 押した位置を維持し、中央を外しても別のタイルに選択が移らないようにする。連続タップをすぐ表示し、保存を順番に行う。失敗した場合は最後に保存できた選択に戻す。保存中は金額の横にスピナーを出し、完了操作を待たせる。
- 他の人の入力がある行だけ、取得数量と残り数を示し、名前ごとの内訳を開閉できるようにする。13個以上は12個ずつ追加表示でき、「数で入力」も開ける。有効な数は自動保存し、不正な数が残る間は完了できない。
- 作成時の金額は、その品の数量分を合計した金額として `合計` と円の単位を添える。`数量 × 行の合計金額` の表示は単価と誤解させるため使わない。
- 税・値引き、端数などの調整額は、発生したときだけ名前と金額を並べる。通常の操作画面に計算方法の説明を常設しない。
- 操作を妨げるエラーや、締め切り・削除の確認には必要な説明を残す。詳しい使い方と計算例はLP・ヘルプで読めるようにし、入力の途中で読む量を増やさない。

## カラー

色は `src/tokens.css` で役割ごとに定義する。`src/styles.css`、`src/selection.css`、`src/landing.css`、`src/camera.css` はこの共通トークンを使う。

| トークン                 | 値        | 用途                             |
| ------------------------ | --------- | -------------------------------- |
| `--color-page`           | `#ffffff` | 白のページ背景                   |
| `--color-surface`        | `#ffffff` | カード、入力、ダイアログ         |
| `--color-surface-subtle` | `#f7f8fa` | 読み取り領域などの薄い背景       |
| `--color-soft`           | `#f0f2f5` | 数量操作、補助領域               |
| `--color-text`           | `#17191e` | 本文・見出し                     |
| `--color-text-muted`     | `#59616f` | 補足・状態                       |
| `--color-action`         | `#bd3425` | 主要操作・選択・合計             |
| `--color-action-hover`   | `#94271c` | 操作のホバー                     |
| `--color-border`         | `#c5cad3` | カードと行の区切り               |
| `--color-control-border` | `#7b8594` | 入力・補助ボタン・選択部品の境界 |
| `--color-selected`       | `#fff0eb` | 選択中の背景                     |
| `--color-warning`        | `#805200` | 選び残しなど確認が必要な状態     |
| `--color-danger`         | `#b42318` | エラー・削除操作のホバー         |

アバターは墨色・朱赤・グレーの背景と、明暗差のある文字色を組み合わせる。ページとカードは白に保ち、薄い朱赤は選択状態に使う。生成りの背景や淡い色の多色使いはしない。確認が必要な状態には黄と説明文を使い、エラーには具体的なメッセージを添える。選択状態は文字やチェックも併用して色だけで伝えない。

## 文字と余白

- フォントは DM Sans と Noto Sans JP。Google Fontsを読み込み、取得できない場合はsans-serifへフォールバックする。レシート見本の数字は `--font-receipt` の等幅フォントを使う。
- 本文13px、一般の操作14px、補足12pxを基本にし、小さな注記とレシートイメージは10px。ページ見出し28px、入力はスマートフォンで16px以上。
- 余白は4px刻み。関連要素は8〜12px、パネル内は16〜28px、セクション間は32px以上を使う。
- 角丸は小部品6px、操作10px、パネル14px、ダイアログ18px。作成画面も共通の操作部品を使い、画面固有の例外を作らない。アバターは円形。
- 影は無彩色の用途別トークンを使う。開始カードとレシートは短い影にし、ダイアログ以外で大きなぼかしを使わない。

## 共通部品

| 部品                              | ルール                                                 |
| --------------------------------- | ------------------------------------------------------ |
| `.button.primary`                 | 朱赤に白文字。次へ進む主要操作                         |
| `.button.secondary`               | 白地に境界線。補助操作                                 |
| `.text-button`                    | 朱赤のテキストと必要なアイコンで示す補助操作           |
| `.icon-button`                    | アイコンのみの操作。名前を付ける                       |
| `input` / `select` / `textarea`   | 見えるラベル、44px以上の高さ、共通の境界線と角丸       |
| `.inline-field`                   | 数量・合計のラベルと入力欄を横並びにする               |
| `.input-with-unit`                | 金額・人数の入力値に円・人の単位を添える               |
| `AmountRatio`                     | 本人の金額 / その品全体の金額。数値の順序と強弱を統一  |
| `.panel`                          | 参加・金額確認など、まとまりを示す領域に限定           |
| `.tabs`                           | 選択中を朱赤の文字と下線で示す                         |
| `.choice-group` / `.radio-option` | 排他的な選択は丸いラジオボタン。選択中は朱赤           |
| `.error`                          | 淡い背景とエラー文を表示                               |
| `.modal`                          | 画面内に収まるサイズ、スクロール可能な内容、閉じる操作 |

ボタンと入力は44px以上を操作高の基準とする。ラジオボタンは丸印と文字をまとめて44px以上のタップ領域にする。他の人の内訳を開く操作も同じ高さを確保する。数量・金額の欄は用途に合わせて幅を決め、円・人の単位を添える。品名は入力値と例で用途を示し、読み上げ用の名前を付ける。キーボードのフォーカスには朱赤の輪郭を付ける。無効な操作は透過で区別し、動きを減らす設定ではアニメーションと遷移を停止する。

760px以下では1列にし、割り勘画面の金額・完了操作を下端に固定する。同じ完了操作を本文中に重ねて表示しない。端末のセーフエリアと本文の下余白を確保する。レシート写真・読み取り原文は内容がある場合に表示する。タッチ端末ではドロップ操作の案内を表示しない。

## 入力から完了まで

- 作成は「飲み会の情報 → 料理・飲み物 → 支払った総額 → 共有リンク」の順。最初に立て替えた本人を含む人数を入力する。作成時の品目設定は「各自／全員で割り勘」のラジオボタンにし、各自を初期値にする。
- 品名の入力欄に、数量・合計の短いラベルと入力欄を並べる。人数は「自分も含めて [人数] 人で割り勘」とし、入力欄の下に同じ内容の注記を置かない。
- 参加者は「食べた・飲んだ分をタップ」に沿ってタイルを選ぶ。全員で分ける料理は「○人で割り勘」にまとめ、最初の人数で計算した金額を明細に含める。料理ごとの選択操作は置かない。
- 合計は本人の入力だけで決まり、他人の参加・入力・削除で変わらない。税・値引きは行の金額に比例して配分し、数量・人数で割り切れない端数は立替者に加算して明示する。
- 「この金額で完了」の保存成功後、本人の金額を大きく表示する。ほかの人の完了を待つ案内を本人の精算条件にしない。保存失敗はエラーへフォーカスし、その場で再試行できるようにする。
- 「選び直す」で戻れる。変更すると入力中に戻り、完了済みの再訪では金額画面から始める。
- 立替者は全員参加・全員完了・数量の残りなしを確認して入力を締め切る。締め切りは全員の編集停止と受け取り記録の開始であり、確認ダイアログで影響を伝える。本人の金額は締め切り前から表示する。
- 既存の会計は計算を変えず、従来の料理選択・全員での金額確定を残す。

入力画面の項目と主ボタンの優先順位は[Walica](https://walica.jp/)を参考にする。操作する対象を質問や動詞で示す考え方は[wariwari](https://wariwari.jp/)と[Wa-Riの公式ガイド](https://ynetlabo.net/guide/wa-ri/)も参考にする。排他的な選択には[GOV.UKのラジオボタン](https://design-system.service.gov.uk/components/radios/)、入力欄には[ラベルを付けたテキスト入力](https://design-system.service.gov.uk/components/text-input/)を参考にし、独自の見た目で操作の意味を変えない。

## LPの説明

冒頭には概要と開始操作を置き、その下で分け方の具体例、使い方、よくある質問を説明する。個人の注文数と全員での割り勘は、料理・飲み物・数量・それぞれの金額を並べて示す。細かな疑問は開閉式のFAQで確認でき、読み終えた場所から開始操作へ戻れるようにする。

説明の量と配置は、[Walica](https://walica.jp/)の概要・特長・手順・末尾の開始ボタンと、[wariwari](https://wariwari.jp/)の使用例・手順・FAQを参考にする。画面の操作ラベルは短く保ち、LPでは初めて使う人が判断に必要な説明を読めるようにする。

## 用途と言葉

家飲みの食材・お酒の買い出しと、居酒屋の会計に絞る。利用者は代金をまとめて立て替えた人と、その飲み会のメンバー。買った人と飲食した人は同じとは限らないため、参加者の操作には「食べた・飲んだ分をタップ」を使う。「自分の数」「自分の注文数」など、何を数えるか考え直す必要のある言い方を避ける。

| 場面                     | 表示する言葉                       |
| ------------------------ | ---------------------------------- |
| 会計全体                 | 割り勘、飲み会の名前               |
| レシートの行             | レシートの内容、料理・飲み物・食材 |
| 1人分ずつ数を選ぶ        | 各自                               |
| 分け合ったものを等分する | ○人で割り勘                        |
| 参加者の選択             | 食べた・飲んだ分をタップ           |
| 参加者全員の金額         | みんなの金額                       |
| 立て替えた本人の金額     | あなたの分                         |
| ほかの参加者の金額       | ○○さんに返す金額                   |
| 選択が足りない状態       | まだ選ばれていないもの、残り       |

個人の注文は飲んだ・食べた数で計算する。みんなで分ける料理・食材は、作成時の人数で割って全員に自動計上する。数量の単位は一律に「個」とせず、杯・本・皿・パックにも共通する数値表示にする。LPの具体例では杯など自然な単位を使う。

LPは居酒屋のドリンクと家飲みの食材で例示する。4人でビール3杯1,800円と唐揚げ1,200円なら、ビール1杯を飲んだ人は900円。サンプルは生ビール・ウーロン茶を個人の注文、唐揚げ・枝豆・ポテトを全員で分ける品として用意する。用語はヘルプ・共有文・APIエラーでも揃える。

実際に操作した参考画面と、採用した判断は [Walicaの操作確認](./walica-interaction-review.md) に記録する。

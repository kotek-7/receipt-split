# レシわけのデザイン

生成りの背景、緑の操作色、丸みのあるカードを基本にする。傾けたレシートや撮影枠のイラストは残し、品目・人数・金額を読む場所には装飾を増やさない。装飾用の英語ラベルや、見出しを繰り返す説明は置かない。

## カラー

色は `src/tokens.css` で役割ごとに定義する。`src/styles.css` と `src/camera.css` はこの共通トークンを使う。

| トークン                 | 値        | 用途                         |
| ------------------------ | --------- | ---------------------------- |
| `--color-page`           | `#fbfcf9` | 生成りのページ背景           |
| `--color-surface`        | `#ffffff` | カード、入力、ダイアログ     |
| `--color-surface-subtle` | `#f7faf3` | 読み取り領域などの薄い背景   |
| `--color-soft`           | `#eff5e9` | 合計、参加者、補助領域       |
| `--color-text`           | `#213a32` | 本文・見出し                 |
| `--color-text-muted`     | `#64746a` | 補足・状態                   |
| `--color-action`         | `#147c64` | 主要操作・選択・合計         |
| `--color-action-hover`   | `#0d614d` | 操作のホバー                 |
| `--color-border`         | `#e3e8df` | カードと行の区切り           |
| `--color-control-border` | `#bdd2be` | 選択部品・読み取り領域の境界 |
| `--color-selected`       | `#f1f8ee` | 選択中の背景                 |
| `--color-warning`        | `#875c3d` | 未割当など確認が必要な状態   |
| `--color-danger`         | `#a24c2d` | エラー・削除操作のホバー     |

アバターは淡い緑・桃・青・紫・黄の専用トークンを使う。エラー、未割当、選択状態は文字やチェックも併用し、色だけで伝えない。

## 文字と余白

- フォントは DM Sans と Noto Sans JP。Google Fontsを読み込み、取得できない場合はsans-serifへフォールバックする。
- 本文13px、一般の操作14px、補足12pxを基本にし、小さな注記とレシートイメージは10px。ページ見出し28px、入力はスマートフォンで16px以上。
- 余白は4px刻み。関連要素は8〜12px、パネル内は16〜28px、セクション間は32px以上を使う。
- 角丸は小部品6px、操作10px、パネル14px、開始カード・ダイアログ18px。アバターと選択マークは円形。
- 影は開始カード・レシート・ダイアログなど、定義済みの用途別トークンを使う。

## 共通部品

| 部品                            | ルール                                                 |
| ------------------------------- | ------------------------------------------------------ |
| `.button.primary`               | 緑地に白文字。次へ進む主要操作                         |
| `.button.secondary`             | 白地に境界線。補助操作                                 |
| `.text-button`                  | 緑のテキストと必要なアイコンで示す補助操作             |
| `.icon-button`                  | アイコンのみの操作。名前を付ける                       |
| `input` / `select` / `textarea` | 共通の境界線と角丸、見えるラベル                       |
| `.panel`                        | 白地・薄い境界線。フォームと品目一覧で共用             |
| `.tabs`                         | 選択中を緑文字と下線で示す                             |
| `.split-mode-choice`            | 選択中を緑の境界・薄い背景・チェックで示す             |
| `.error`                        | 淡い背景とエラー文を表示                               |
| `.modal`                        | 画面内に収まるサイズ、スクロール可能な内容、閉じる操作 |

ボタンと入力は44px以上を操作高の基準とし、一覧内の小さなアイコン操作は既存の配置を維持する。キーボードのフォーカスには緑の輪郭を付ける。無効な操作は透過で区別し、動きを減らす設定ではアニメーションと遷移を停止する。

760px以下では1列にし、精算画面の金額・完了操作を下端に固定する。端末のセーフエリアと本文の下余白を確保する。レシート写真・読み取り原文は内容がある場合に表示する。タッチ端末ではドロップ操作の案内を表示しない。

## 参考

役割ごとの色分けは[デジタル庁デザインシステムのカラー](https://design.digital.go.jp/dads/foundations/color/)、文字・レイアウト・余白の一貫性は[GOV.UK Design SystemのStyles](https://design-system.service.gov.uk/styles/)を参考に、レシわけの画面に合わせて定義した。

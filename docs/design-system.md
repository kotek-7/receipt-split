# レシわけのデザイン

白・墨色・朱赤を基本に、余白、文字の強弱、線の太さで情報の順序を作る。見出しの小さな朱赤の斜線や、金額欄の上辺などに特徴を持たせる。レシートの見本はLPの一箇所に置き、紙の切り口を各画面へ繰り返さない。装飾用の英語ラベルや、見出しを繰り返す説明は置かない。入力内容・操作の順序・確定ややり直しの条件は、その画面に説明を置く。

## 視覚的な工夫

- ロゴとfaviconは、1枚のレシートを2片に分けた共通マークを使う。
- LPの見出しは朱赤の下線、冒頭のレシート見本は傾きと紙の切り口で特徴をつける。
- 見本の金額と手順番号には等幅フォントを使う。手順番号は小さな番号札として示す。
- 作成画面は外枠を置かず、入力の下線とセクション間の余白で区切る。品目は薄い横線、一覧の見出しは太い横線で階層を分ける。
- 選択画面は行全体を着色せず、操作部品と自分の金額に選択状態を表す。

## カラー

色は `src/tokens.css` で役割ごとに定義する。`src/styles.css`、`src/selection.css`、`src/landing.css`、`src/camera.css` はこの共通トークンを使う。

| トークン                 | 値        | 用途                             |
| ------------------------ | --------- | -------------------------------- |
| `--color-page`           | `#ffffff` | 白のページ背景                   |
| `--color-surface`        | `#ffffff` | カード、入力、ダイアログ         |
| `--color-surface-subtle` | `#f7f8fa` | 読み取り領域などの薄い背景       |
| `--color-soft`           | `#f0f2f5` | 数量操作、補助領域               |
| `--color-text`           | `#17191e` | 本文・見出し                     |
| `--color-text-muted`     | `#59616f` | 補足・状態                       |
| `--color-action`         | `#bd3425` | 主要操作・選択・合計             |
| `--color-action-hover`   | `#94271c` | 操作のホバー                     |
| `--color-border`         | `#c5cad3` | カードと行の区切り               |
| `--color-control-border` | `#7b8594` | 入力・補助ボタン・選択部品の境界 |
| `--color-selected`       | `#fff0eb` | 選択中の背景                     |
| `--color-warning`        | `#805200` | 選び残しなど確認が必要な状態     |
| `--color-danger`         | `#b42318` | エラー・削除操作のホバー         |

アバターは墨色・朱赤・グレーの背景と、明暗差のある文字色を組み合わせる。ページとカードは白に保ち、薄い朱赤は選択状態に使う。生成りの背景や淡い色の多色使いはしない。確認が必要な状態には黄と説明文を使い、エラーには具体的なメッセージを添える。選択状態は文字やチェックも併用して色だけで伝えない。

## 文字と余白

- フォントは DM Sans と Noto Sans JP。Google Fontsを読み込み、取得できない場合はsans-serifへフォールバックする。レシート見本の数字は `--font-receipt` の等幅フォントを使う。
- 本文13px、一般の操作14px、補足12pxを基本にし、小さな注記とレシートイメージは10px。ページ見出し28px、入力はスマートフォンで16px以上。
- 余白は4px刻み。関連要素は8〜12px、パネル内は16〜28px、セクション間は32px以上を使う。
- 角丸は小部品6px、操作10px、パネル14px、ダイアログ18px。作成画面の入力は角丸を付けず、下線のみとする。アバターは円形。
- 影は無彩色の用途別トークンを使う。開始カードとレシートは短い影にし、ダイアログ以外で大きなぼかしを使わない。

## 共通部品

| 部品                            | ルール                                                 |
| ------------------------------- | ------------------------------------------------------ |
| `.button.primary`               | 朱赤に白文字。次へ進む主要操作                         |
| `.button.secondary`             | 白地に境界線。補助操作                                 |
| `.text-button`                  | 朱赤のテキストと必要なアイコンで示す補助操作           |
| `.icon-button`                  | アイコンのみの操作。名前を付ける                       |
| `input` / `select` / `textarea` | 見えるラベル。作成画面は下線、その他は境界線と角丸     |
| `.panel`                        | 参加・金額確認など、まとまりを示す領域に限定           |
| `.tabs`                         | 選択中を朱赤の文字と下線で示す                         |
| `.split-mode-choice`            | 一体の切り替え。選択中は墨色に白文字                   |
| `.error`                        | 淡い背景とエラー文を表示                               |
| `.modal`                        | 画面内に収まるサイズ、スクロール可能な内容、閉じる操作 |

ボタンと入力は44px以上を操作高の基準とし、一覧内の小さなアイコン操作は既存の配置を維持する。キーボードのフォーカスには朱赤の輪郭を付ける。無効な操作は透過で区別し、動きを減らす設定ではアニメーションと遷移を停止する。

760px以下では1列にし、割り勘画面の金額・完了操作を下端に固定する。同じ完了操作を本文中に重ねて表示しない。端末のセーフエリアと本文の下余白を確保する。レシート写真・読み取り原文は内容がある場合に表示する。タッチ端末ではドロップ操作の案内を表示しない。

## 入力から完了まで

- 作成は「飲み会の情報 → レシートの内容 → 支払った総額 → 共有リンク」の順。分け方は各行の小さな切り替えで指定し、各自を初期値にする。
- 選択は数量とシェアの2群に分け、それぞれの見出しで操作を説明する。数量は＋／−、シェアは「選ぶ／選択済み」を行の右側に置く。
- 全体金額には「全体」と付け、自分の負担を別に表示する。全品選択を求めるように見える「選択数／全品数」は使わない。
- 「選択を終える」の保存成功後に金額画面へ進み、待ち人数や確定の操作を案内する。保存失敗はエラーへフォーカスし、選択画面から再試行できるようにする。
- 完了後は「自分の分を選び直す」で戻れる。選択を変えると入力中に戻る。完了済みの参加者が再訪したときは金額画面から始める。

入力画面の項目と主ボタンの優先順位は[Walica](https://walica.jp/)を参考にする。操作する対象を質問や動詞で示す考え方は[wariwari](https://wariwari.jp/)と[Wa-Riの公式ガイド](https://ynetlabo.net/guide/wa-ri/)も参考にし、レシわけの品目選択に合わせる。

## LPの説明

冒頭には概要と開始操作を置き、その下で分け方の具体例、使い方、よくある質問を説明する。各自とシェアの違いは、料理・飲み物・数量・それぞれの金額を並べて示す。細かな疑問は開閉式のFAQで確認でき、読み終えた場所から開始操作へ戻れるようにする。

説明の量と配置は、[Walica](https://walica.jp/)の概要・特長・手順・末尾の開始ボタンと、[wariwari](https://wariwari.jp/)の使用例・手順・FAQを参考にする。画面の操作ラベルは短く保ち、LPでは初めて使う人が判断に必要な説明を読めるようにする。

## 参考

役割ごとの色分けは[デジタル庁デザインシステムのカラー](https://design.digital.go.jp/dads/foundations/color/)、文字・レイアウト・余白の一貫性は[GOV.UK Design SystemのStyles](https://design-system.service.gov.uk/styles/)を参考に、レシわけの画面に合わせて定義した。

## 用途と言葉

家飲みの食材・お酒の買い出しと、居酒屋の会計に絞る。利用者は代金をまとめて立て替えた人と、その飲み会のメンバー。買った人と飲食した人は同じとは限らないため、参加者の操作は「飲んだもの・食べたものを選ぶ」と説明する。

| 場面                     | 表示する言葉                       |
| ------------------------ | ---------------------------------- |
| 会計全体                 | 割り勘、飲み会の名前               |
| レシートの行             | レシートの内容、料理・飲み物・食材 |
| 1人分ずつ数を選ぶ        | 各自                               |
| 分け合ったものを等分する | シェア                             |
| 参加者の画面             | 自分の分、みんなの金額             |
| 立て替えた本人の金額     | あなたの分                         |
| ほかの参加者の金額       | ○○さんに返す金額                   |
| 選択が足りない状態       | まだ選ばれていないもの、残り       |

「各自」は飲んだ・食べた数、「シェア」は一緒に飲食した人が選ぶことを、作成画面と選択画面で説明する。「みんなで割る」は全参加者に自動で等分する意味に見えるため使わない。数量の単位は一律に「個」とせず、杯・本・皿・パックにも共通する数値表示にする。LPの具体例では杯など自然な単位を使う。

LPは居酒屋のドリンクと家飲みの食材で例示する。サンプルは生ビール・ウーロン茶を「各自」、唐揚げ・枝豆・ポテトを「シェア」にして、どちらの操作も試せるようにする。用語はヘルプ・共有文・APIエラーでも揃える。

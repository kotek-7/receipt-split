# Walicaの操作確認

2026年9月30日、[Walica](https://walica.jp/)の公開Webアプリをブラウザで操作。参考用の架空グループを作成し、390px幅を中心に、2人と3人の入力・登録・更新・清算確認を行った。

## 操作して確認したこと

| 操作                  | 実際の挙動                                                                                                           | レシわけに取り入れる点                                       |
| --------------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| グループ作成          | 名前を入力して追加すると、その場にメンバーが並ぶ。外貨は必要な場合だけ開く                                           | よく使う入力を先に見せ、追加機能は必要な時に開く             |
| 2人の「かんたん入力」 | 支払った人の欄を1回押すと、2人の名前が交代する。別の選択画面は開かない                                               | 目の前の対象を直接押せる操作を優先する                       |
| 3人の支払った人の変更 | 名前を押すと3人の選択肢が開く。選ぶと文中の名前が変わる                                                              | 選択肢の数に合った部品を使う                                 |
| 負担する人の変更      | 名前がチェックと並び、本人を含めて個別に外せる                                                                       | 状態と操作対象を同じ場所に置く                               |
| 件名・金額入力        | 「[人] が [対象者] の [件名] を払って、[金額] かかった。」と読める                                                   | 立替者・人数の欄を文として読める並びにする                   |
| 入力方式の切り替え    | 件名と支払った人は引き継ぎ、こだわり入力では人ごとの金額と合計を表示。かんたん入力に戻ると、それまでの合計入力が残る | 金額や状態を別の説明文へ移さず、操作のすぐ近くに示す         |
| 登録                  | 2人の3,000円を登録すると一覧へ戻り、「あおい → はる」「1,500円」を表示                                               | 完了後は返す相手と金額を主役にする                           |
| 修正                  | 一覧の品名横の鉛筆から同じフォームへ戻る。対象を1人、金額を2,400円に変えて更新すると、清算額も2,400円に変わった      | 修正時も同じ操作を使い、別の入力方法を覚えさせない           |
| 3人の個別額登録       | 500・300・400円を入れると合計1,200円。その支払いを登録すると、先の立て替えと合わせた清算先・金額へ更新された         | 入力の途中にも合計を見せ、完了前に結果を判断できるようにする |
| 明細                  | 「明細を見る」で「貸し借り／支出」を切り替えられる。戻ると簡潔な清算一覧に戻る                                       | 初期画面の情報を絞り、内訳は開いて確認できるようにする       |

## レシわけでの具体化

作成画面は「[名前] が立て替え」「自分も含めて [人数] 人で割り勘」と入力欄を並べる。参加者は1杯・1品ずつのタイルを食べた・飲んだ分だけ選び、本人の金額と選択数を `600 / 1,800円`、`1 / 3` で確認する。

タイルはレシわけ独自の操作として実装する。選択済みにはチェック、ほかの人の分には人物マークを付ける。タイルを連続して押せるようにし、押した位置を保ったまま保存する。金額の保存が終わるまで完了操作を待たせる。

個々の杯を選ぶのは各自の注文だけとする。みんなで分ける料理代は作成時の人数から自動計算し、参加者に共有料理の選び直しを求めない。

## 確認時の制約

今回のブラウザでは、かんたん入力の整数金額にHTMLの刻み値エラーが出た。ブラウザが提示した有効値で登録・更新を続け、一覧で整数の表示を確認した。全対象者を外した際のダイアログはブラウザ操作を止めたため、閉じてもらって確認を再開した。これらの挙動を入力設計の参考にはしない。

画面の評価は操作時点のもの。外貨や広告機能は、今回の料理・飲み物の選択フローの対象に含めていない。
